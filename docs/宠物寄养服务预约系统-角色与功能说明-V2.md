# 宠物寄养服务预约系统 · 角色与功能说明（V2 丰富版）

> 版本：V2.0 · 2026-10-30
> 说明：在 V1.0 基础上，对各角色功能**做系统性扩充与归类**，新增「消息与触达、营销与会员、售后与保障、经营分析」等能力域，并给出完整的**功能全景图、权限矩阵、协作流程与扩展规划**。作为需求评审、开发排期与测试用例基线，与《软件设计文档》《数据库设计文档》配套。

## 〇、功能全景图

系统按「端 × 角色 × 功能域」三层组织，功能域全景如下：

```
                 ┌───────────────────────────────────────────────┐
                 │              管理后台（Web）· 管理员             │
                 │  总览-看板  业务-机构/订单/宠物/动态/评价        │
                 │  运营-容量/匹配  系统-用户/权限/审计             │
                 └───────────────────────────────────────────────┘
                                      │ 平台审核/监管
        ┌─────────────────────────────┼─────────────────────────────┐
        │                             │                             │
┌───────▼────────┐          ┌─────────▼─────────┐          ┌────────▼────────┐
│  主人 C端        │          │   机构 C端         │          │   访客（前置）    │
│ (小程序/KMP)    │          │ (小程序/KMP)      │          │ (小程序/KMP)     │
│  宠物档案        │          │  机构资料/容量      │          │  浏览/筛选/详情   │
│  找机构/预约     │ ──下单──▶│  接单/确认         │          │  (引导注册转化)   │
│  看动态/评价     │ ◀──动态──│  发布动态/回复评价  │          │                 │
│  订单/支付       │          │  定价/收益         │          │                 │
└─────────────────┘          └───────────────────┘          └─────────────────┘
```

- **主人**与**机构**在 C 端（小程序 / KMP）完成业务闭环，两者通过「订单」「动态」「评价」三组实体协作。
- **管理员**在管理后台做**跨角色监管与运营治理**。
- **访客**是转化漏斗入口，登录后升级为主人。

## 一、角色总览

| 角色 | 简称 | 使用端 | 一句话职责 |
| --- | --- | --- | --- |
| 访客 | guest | 小程序 / KMP | 未登录即可浏览机构，点击预约/收藏时引导注册 |
| 主人 | owner | 小程序 / KMP | 宠物档案、找机构、预约下单、看动态、评价、售后 |
| 机构 | sitter | 小程序 / KMP | 维护本机构资料与容量、接单确认、发布动态、回复评价、管理收益 |
| 管理员 | admin | 管理后台（Web） | 平台运营与监管：审核、看板、容量治理、智能匹配、用户与权限、审计 |

> 角色非互斥：同一账号可既为主人又运营机构；管理员账号由平台后台创建，与 C 端账号隔离。

## 二、主人（owner）功能清单

C 端核心角色，覆盖「养宠 → 找机构 → 预约 → 寄养中 → 售后 → 复购」完整生命周期：

### 2.1 宠物档案管理
- 新增宠物：类型、名字、体型、年龄、**疫苗情况、绝育/健康备注**、照片
- 编辑 / 删除 / 归档宠物档案
- **免疫证明上传**（接种证/疫苗本照片）与平台核验状态跟踪（已核验 / 待核验 / 缺证明）
- **多宠物管理**：一个账号可维护多只宠物，预约时按宠物卡片快速选择
- 宠物**健康与行为备注**（忌口、性格、过敏史、常用用品），供机构照料参考
- 宠物历史寄养记录（随订单自动沉淀）

### 2.2 找机构与筛选
- 机构列表 / 详情查看（环境照片、日单价、评分、地址、类型、简介、环境标签）
- 多维度筛选：类型（家庭 / 门店 / 上门喂养）、价格区间、评分、距离、容量余量
- 排序：综合 / 评分 / 价格 / 距离
- **智能推荐**：基于 pgvector 语义匹配（如「能收胆小的猫、环境安静」→ 推荐独立猫舍）
- **容量日历**：查看机构逐日床位余量，避开满员日期
- 机构**收藏 / 对比**（收藏夹常驻，方便复购）

### 2.3 在线预约与费用计算
- 下单流程：选择机构 → 选择寄养起止日期 → 选择宠物 → 系统自动算费
  - 家庭 / 门店寄养：`天数 × 日单价`（天数 = 结束 − 开始，含首不含尾）
  - 上门喂养：`次数 × 次单价`
- **费用明细预览**：单价 × 天数 + 附加项（节假日上浮、加购服务如遛宠/洗澡/视频）− 优惠（券/积分抵扣）
- 提价 / 改期时**实时重算**金额
- 提交订单 → 待支付；查看并确认《寄养服务协议》
- 支付：模拟支付闭环（余额 / 模拟通道；个人主体无微信支付资质）

### 2.4 订单管理
- 我的订单列表 / 详情，按状态筛选
- 状态跟踪：`待支付 → 待确认 → 寄养中 → 已结束 → 已评价`（含 已取消 / 退款中）
- 取消订单（支付前 / 寄养前可退）、**改期 / 续费 / 加购服务**
- 待支付订单**限时支付**（超时自动取消并释放床位）
- 申请退款 / 查看退款进度（配合售后）

### 2.5 寄养动态
- 寄养期间实时查看机构发布的图文动态（近况、照片、每日打卡、视频）
- 对动态点赞 / 留言，与机构互动
- **订阅通知**：新动态 / 订单状态变更推送（微信订阅消息）

### 2.6 评价与口碑
- 寄养结束后评价：**四维评分**（环境 / 服务 / 安全 / 性价比）+ 文字 + 照片
- 评价后 24h 内可补充 / 追评
- 查看机构口碑聚合（平均分、各维度分、好评率）与全部评价
- 机构回复后可互动

### 2.7 售后与保障
- 申请退款 / 售后单（寄养中出现异常）
- 联系客服（在线客服 / 工单）
- 平台申诉（对机构争议处理）

### 2.8 个人中心
- 个人资料、地址 / 联系人维护
- 我的宠物 / 订单 / 收藏 / 优惠券 / 积分 / 消息通知
- 账号设置：绑定微信、手机号、隐私授权（如允许机构查看宠物健康备注）

## 三、机构（sitter）功能清单

寄养服务提供方，数据隔离在本机构范围，负责「资料 → 接单 → 照料 → 动态 → 评价 → 收益」闭环：

### 3.1 机构资料与资质
- 维护机构信息：环境照片、类型、地址、日单价、简介、**环境标签 / 服务项目**
- 提交入驻资料，等待平台审核（审核通过后上架）
- 维护**可同时容量**（家庭 / 门店各类型床位）
- 资质与证照上传（营业执照 / 场地照片）供平台审核

### 3.2 容量与定价
- 容量日历：逐日床位占用，直观看到满员/余量
- 设置节假日 / 旺季**上浮定价规则**
- **加购服务定价**（遛宠、洗澡、视频陪伴等附加项）
- 查看每日可接订单余量，超容量自动拦截下单

### 3.3 接单与照料
- 新订单提醒、**确认 / 拒绝**预约（拒绝需填原因）
- 查看订单内宠物档案（含健康备注、免疫证明核验状态）
- 管理进行中订单（寄养中 → 已结束）
- 登记照料记录（喂食 / 遛宠 / 健康状态，可转为动态素材）

### 3.4 寄养动态发布
- 寄养期间发布图文 / 视频动态，记录宠物近况与每日打卡
- 动态提交后经**平台审核**，通过后对主人可见
- 管理已发动态（上架 / 下架 / 置顶）

### 3.5 评价与互动
- 查看主人评价与四维评分
- **回复评价**，处理差评沟通
- 查看本机构口碑聚合与趋势

### 3.6 收益与结算
- 收益明细：各订单收入、平台抽佣、可结算金额
- 结算申请 / 提现记录
- 订单收入报表导出（按日 / 周 / 月）

### 3.7 门店运营辅助（门店寄养特有）
- 门店端订单看板、今日待办（待确认 / 待接宠 / 待完成）
- 寄养区 / 笼位编号管理（对应容量日历）

### 3.8 不具备
- 查看 / 修改其他机构数据
- 平台级审核与监管（动态审核、评价治理、用户管理）

## 四、管理员（admin）功能清单

平台运营与治理，分 4 大管理域（管理后台导航已对应落地）：

### 4.1 经营看板（总览）
- 核心指标：GMV / 订单量 / 入住率 / 平台综合评分 / 新增用户 / 活跃机构
- 14 日收入趋势（折线 + 面积）、订单 / 宠物增长趋势
- **旺季预警**（节假日容量紧张）、**差评预警**（待跟进评价）
- 平台各类型机构占比、Top 机构排行
- **经营报表导出**（收入 / 订单 / 用户明细，CSV/Excel）

### 4.2 业务管理
- **机构管理**：入驻审核（通过 / 驳回）、上下架、编辑机构信息、容量治理、机构处罚（限流 / 下架）
- **订单管理**：全量订单、状态调整、异常订单处理（改期 / 退款 / 赔付）
- **宠物管理**：全平台宠物档案、**免疫证明核验**（核验 / 待核验 / 缺证明）
- **寄养动态管理**：审核机构动态（通过 / 驳回 / 下架），处置违规内容
- **评价管理**：四维评价查看、内容审核、隐藏违规评价、**舆情预警与跟进**

### 4.3 运营治理
- **容量日历**：跨机构逐日床位排期、节假日紧张度、入住率预测、节假日定价配置
- **智能匹配**：配置 pgvector 参数（相似度阈值 / 召回数量 / 向量维度 / HNSW 索引）、预览语义匹配、监控向量索引状态
- **营销配置**：优惠券 / 满减 / 新人礼 / 活动 Banner 位配置
- **消息触达**：订阅消息模板管理、推送任务、公告发布

### 4.4 系统管理
- **用户管理**：全平台账号、角色分配（主人 / 机构 / 管理员）、启用 / 禁用、邀请用户
- **权限与角色**：角色权限点配置、管理员分级（运营 / 审核 / 超级管理员）
- **审计日志**：后台操作留痕、关键操作（审核 / 下架 / 退款 / 用户启停）审计
- **数据字典 / 配置**：寄养类型、环境标签、评价维度等枚举维护

### 4.5 不具备
- 代替主人下单、代替机构发布动态（各角色在权限边界内操作）

## 六、关键业务流程中的角色协作

### 6.1 一次完整预约（主人 × 机构 × 管理员）

```
主人选择机构 → 选日期 → 选宠物 → 系统算费(天数×日单价+附加-优惠)
  → 提交订单(待支付) → 限时支付(超时自动取消释放床位)
  → 机构确认(待确认→寄养中)
  → 机构发布动态(→管理员审核→通过→主人可见/点赞)
  → 机构完成订单(寄养中→已结束)
  → 主人四维评价(已结束→已评价) → 机构回复 → 平台舆情监测
```

### 6.2 机构入驻与治理（机构 × 管理员）

```
机构提交资料/证照 → 管理员审核(通过/驳回) → 上架
  → 机构维护容量/定价 → 接单
  → 出现违规 → 管理员处罚(限流/下架)
```

### 6.3 免疫证明核验（主人 × 管理员）

```
主人上传免疫证明 → 管理员核验(已核验/待核验/缺证明)
  → 已核验后可正常下单；缺证明提醒补传
```

### 6.4 售后与退款（主人 × 机构 × 管理员）

```
主人申请退款/售后 → 机构处理(同意/驳回) → 管理员审核
  → 退款到账 → 订单标记退款中/已取消 → 释放床位 → 审计留痕
```

### 6.5 数据所有权边界（关键约束）

- **主人**：只读写「自己的宠物、订单、评价、优惠、工单」
- **机构**：只读写「自己机构的资料、容量、订单、动态、评价回复、收益」
- **管理员**：跨机构 / 跨用户全量读写，承担审核、监管、治理与审计职责

> 对应数据库的多实体关联：`user(role) → pet(归属主人) → order(主人+机构) → dynamic / review(机构+主人)`；后台按 `role + owner_id` 做数据隔离，审计表记录关键操作。

| P2 | 售后退款流程 + 客服工单 | 三方 | 异常场景闭环 |
| P2 | 经营看板 + 报表导出 | 管理员 | 平台经营决策 |
| P2 | 权限点配置 + 审计日志 | 管理员 | 多角色权限考察重点 |

## 八、角色演进与扩展预留

- **访客 → 主人**：微信授权 / 手机号注册后即为主人
- **主人 → 机构**：同一账号可额外申请成为机构（后台二次资料审核）
- **管理员分级（预留）**：运营管理员 / 审核管理员 / 超级管理员，细分权限点
- **运营平台化（预留）**：独立客服角色、财务角色可并入管理员体系做细粒度授权
