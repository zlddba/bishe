# 宠栖 PatNest · 隐私与个人信息说明

> 版本：V1.0 · 2026-11-04
> 用途：说明系统收集哪些个人信息、用于什么目的、谁能看到、保存多久，以及用户如何行使删除权。
> 关联：`docs/02-数据库设计.md`（字段定义）、`docs/03-接口文档.md`（接口契约）、`docs/12-后端权限与限流收紧说明.md` §2.3（管理员权限）

---

## 1 适用范围

本说明覆盖三类主体：

| 主体 | 说明 |
|---|---|
| 宠物主人（`owner`） | 注册后浏览机构、建宠物档案、下单、评价 |
| 寄养机构（`sitter`） | 提交入驻资料、接单、发布寄养动态、结算 |
| 平台管理员（`admin`） | 审核、客服、审计，属于内部处理者 |

小程序（`uniapp/`）目前只有脚手架，未接入接口；接入后须复用本说明并补充微信侧授权条款。

## 2 收集的个人信息与用途

### 2.1 账号与联系方式

| 字段 | 表 | 是否必填 | 用途 |
|---|---|---|---|
| `username` | `users` | 是 | 登录标识 |
| `password_hash` | `users` | 是 | 仅存 bcrypt 哈希，不可逆 |
| `nickname` | `users` | 否 | 展示名称 |
| `phone` | `users` | 否（全表唯一） | 注册查重、客服联系、账号找回 |
| `email` | `users` | 否 | 通知与找回 |
| `avatar_url` | `users` | 否 | 头像展示 |
| `address` / `contact_name` / `contact_phone` | `users` | 否 | 默认联系信息，下单时可复用 |

**公开可见性**：机构公开接口（`/sitters`、`/sitters/:id` 等）不返回联系人、手机号、营业执照；评价列表只返回脱敏昵称（`nickname` 为空时回退 `username`）。

### 2.2 宠物档案

| 字段 | 表 | 用途 |
|---|---|---|
| `name` / `species` / `breed` / `body_size` / `age_month` / `weight_kg` | `pets` | 匹配寄养条件、生成订单 |
| `vaccinated` / `sterilized` / `vaccine_urls` / `vaccine_status` / `vaccine_note` | `pets` | 健康与免疫核验（管理员可核验） |
| `photo_urls` / `avatar_url` / `notes` | `pets` | 展示与照护备注 |

宠物资料仅本人、承接该订单的机构、管理员可见。

### 2.3 机构资质

| 字段 | 表 | 用途 |
|---|---|---|
| `contact_person` | `sitters` | 平台审核与客服联系 |
| `license_photo_url` / `id_card_photo_url` | `sitters` | 入驻资质核验，**仅管理员可见**，不出现在任何公开接口 |

### 2.4 订单与支付

| 字段 | 表 | 用途 |
|---|---|---|
| 订单日期、宠物、金额、状态、备注 | `orders` / `order_pet` | 履约与对账 |
| `transaction_id` / `raw_response` | `payments` | 支付流水（当前为 mock） |
| 退款原因、结算周期 | `refund_requests` / `sitter_settlements` | 售后与结算 |

### 2.5 位置信息

| 字段 | 表 | 用途 |
|---|---|---|
| 机构 `latitude` / `longitude` | `sitters` | 地图展示与距离排序 |
| 地理编码结果 | `geocode_cache` | 地址转坐标，避免重复调用高德 |
| 一次性选点会话 | `geo_pick_sessions` | 桌面端地图选点，5 分钟过期、取走即删 |

高德 Web 服务 Key 只保留在后端；客户端不直接持有。定位权限仅在小程序/App 申请前台定位，**不申请后台定位**（见 `docs/10` §6）。

### 2.6 日志与审计

| 字段 | 表 | 用途 |
|---|---|---|
| `actor_id` / `action` / `resource_type` / `resource_id` / `detail` | `audit_logs` | 后台与机构端关键操作追溯 |
| `ip_address` / `user_agent` | `audit_logs` | 预留字段；当前调用未传 IP，实际为 `NULL` |
| `token_hash` | `refresh_tokens` | 只存 SHA-256，用于刷新与吊销 |

## 3 谁能看到什么

| 数据 | 本人 | 对方用户 | 机构 | 管理员 | 游客 |
|---|---|---|---|---|---|
| 账号 / 手机号 / 邮箱 | 是 | 否 | 否 | 是（客服与审核需要） | 否 |
| 宠物档案 | 是 | 否 | 仅承接订单的机构 | 是 | 否 |
| 免疫证明 | 是 | 否 | 仅承接订单的机构 | 是（核验） | 否 |
| 机构资质照片 | — | 否 | 仅本机构 | 是 | 否 |
| 订单与支付 | 是 | 否 | 仅本机构订单 | 是 | 否 |
| 评价 | 是 | 否 | 是（可回复） | 是 | 是（脱敏昵称） |
| 寄养动态 | 订单主人 | 否 | 本机构 | 是 | 否 |

管理员侧的行级保护见 `docs/12` §2.3：改动管理员账号的角色/状态/密码、删除管理员账号，只有内置 `admin` 可做；最后一个可用管理员不可禁用或降级。

## 4 保存期限与删除

| 数据 | 期限 | 实现 |
|---|---|---|
| 访问令牌 | 30 分钟（`JWT_ACCESS_TTL_MINUTES`） | 无状态 JWT，`token_invalid_at` 可提前作废 |
| 刷新令牌 | 7 天，且每次刷新轮换、旧的立即吊销 | `refresh_tokens.expires_at` / `revoked_at` |
| 注销申请 | 3 天冷静期，期间登录自动撤销 | `users.cancel_deadline` + account-cancel worker |
| 注销后账户 | 无业务数据则物理删除；有订单等 RESTRICT 引用则软删除，进后台"已注销"列表 | `purgeUserAccount` |
| 审计日志 | 规划 6 个月归档，**当前没有自动清理任务** | `audit_logs` |
| 地理编码缓存 | 180 天 | `geocode_cache` + `geocodeCacheTTL` |
| 选点会话 | 5 分钟 | `geo_pick_sessions.expires_at` |

用户行使删除权：主人端调用 `POST /pet-owner/account/cancel-request`（`mode=account`）；机构只想下架机构时用 `mode=sitter`，账号保留、角色退回 `owner`。

## 5 第三方共享

| 第三方 | 共享内容 | 场景 |
|---|---|---|
| 高德地图（Amap） | 机构地址或坐标 | 地址解析、静态地图、瓦片、逆地理编码 |
| MinIO（自建对象存储） | 用户上传的图片 | 头像、宠物照片、动态图、评价图、资质照片 |

除上述必要调用外，不向第三方出售或共享个人信息。短信与微信通道在演示环境为模拟，不实际外发。

---

## 6 安全措施

- 传输：生产走 HTTPS；开发/演示期明文 HTTP，仅限内网与答辩现场。
- 存储：密码 bcrypt；刷新令牌只存 SHA-256；资质照片仅管理员接口返回。
- 鉴权：JWT + 角色中间件 + 行级归属校验；动态互动有参与者校验；CORS 白名单；注册/刷新/上传/地理编码限流。
- 会话：禁用、删除、重置密码、登出、申请注销后旧令牌立即失效。
