## 发布说明（`release/`）

每个 tag 一份，**文件正文即 GitHub Release 页的发布内容**；文件名必须与 tag 严格对应，否则流水线的 `verify` 会直接失败。

| 文件 | 内容 |
|---|---|
| `release/TEMPLATE.md` | 发布说明模板：版本亮点 / 新增功能 / 问题修复 / 升级说明 / 已知问题 / 校验 |

| `release/v2.0.3.md` | 维护版：KMP 全列表页下拉刷新、后端代录评价状态同步 |
