# docs

毕业设计的过程文档都放这里，和代码同仓库、同提交历史。

建议按顺序维护：

| 文件 | 内容 |
|---|---|
| `01-需求规格.md` | 选题背景、用户角色、功能清单、用例 |
| `02-数据库设计.md` | ER 图、表结构、字段说明 |
| `03-接口文档.md` | 路径、方法、请求/响应示例、错误码 |
| `04-部署与热更新.md` | 环境要求、蓝绿发布、数据库在线迁移、管理面板热更新 |
| `05-编译打包发布运行.md` | 本机构建、容器打包、服务器发布、回滚与运维 |
| `06-论文素材.md` | 截图、测试记录、参考文献 |

接口文档可以先手写，等后端路由稳定后再考虑用 Swagger/OpenAPI 生成。
