# PatNest 宠栖 v2.0.2

v2.0.1 之后的维护版本，**不涉及服务端接口与数据库变更**。两个重点：一是补齐架构矩阵——服务端部署包、Linux 桌面、Windows 桌面新增 arm64 版本，Android 收窄为仅 arm64-v8a；二是统一所有产物的命名规范，让附件名一看就知道是什么、给谁用。

## 版本亮点

- 服务端部署包、Linux 桌面四种格式、Windows msi 全部提供 amd64 / x64 与 arm64 双架构。
- Android 收窄为仅 arm64-v8a，安装包更小，不再向 32 位设备分发。
- 所有产物统一为 `patnest-<版本>-<平台>-<架构>.<格式>`，架构标识必写，不再出现同名不同架构混在一起的情况。

## 新增功能

| 模块 | 内容 |
| --- | --- |
| 服务端 | 新增 `patnest-server-<版本>-linux-arm64.zip` 部署包，与 amd64 版并列发布；容器镜像由目标架构宿主机本地构建（`alpine` / `nginx` 基础镜像均为多架构） |
| Linux 桌面 | 新增 arm64 版 deb / rpm / AppImage / tar.gz，在 `ubuntu-24.04-arm` runner 上原生构建 |
| Windows 桌面 | 新增 arm64 版 msi，在 `windows-11-arm` runner 上原生构建 |
| 工程 | 产物命名统一：`patnest-<版本>-<平台>-<架构>.<格式>`，架构标识必写 |

## 问题修复

| 模块 | 问题 | 处理 |
| --- | --- | --- |
| Android | v2.0.0 / v2.0.1 的 APK 含 32 位 ARM 库（armeabi-v7a），与「仅 arm64」的预期不符 | `ndk.abiFilters` 收窄为 `arm64-v8a`，CI 上传前校验包内无 32 位库 |
| 桌面端 | 安装包名沿用 Java applicationId（`team.wd.atnestapp-*`），难以辨认 | 产品名改为 `patnest`，分发文件统一重命名 |
| 服务端 | amd64 部署包名不带架构后缀，与 arm64 版并列时无法区分 | 包名统一为 `patnest-server-<版本>-linux-<arch>`，amd64 也带后缀 |
| 桌面端 | Linux 产物同时出现 `x64` / `x86_64` / `amd64` 三种写法 | 统一为 `amd64` / `arm64` 两种 |

## 升级说明

- **服务端**：无需数据库迁移、无接口变更。按服务器架构选择部署包：
  ```bash
  # amd64 服务器
  unzip patnest-server-2.0.2-linux-amd64.zip && cd patnest-server-2.0.2-linux-amd64
  # arm64 服务器
  unzip patnest-server-2.0.2-linux-arm64.zip && cd patnest-server-2.0.2-linux-arm64
  cp .env.example .env      # 沿用既有 .env 亦可
  bash scripts/install.sh
  ```
  容器镜像在服务器本地按宿主架构构建，无需额外配置。
- **桌面端**：
  - Linux：amd64 / arm64 各有 deb、rpm、AppImage、tar.gz，按发行版与架构选择；
  - Windows：x64 与 arm64 两个 msi；arm64 设备（如 Surface Pro X 系）选 `windows-arm64`；
  - macOS：仍仅 Apple Silicon（arm64）。
- **Android**：仅支持 arm64-v8a 设备；32 位 ARM 与 x86 设备请继续使用 v2.0.1。
- **小程序**：下载工程包后用 HBuilderX 重新导入发行。

## 产物与架构

| 端 | 支持架构 | 附件 |
| --- | --- | --- |
| 服务端 / 容器 | amd64 + arm64 | `patnest-server-2.0.2-linux-<arch>.zip` |
| Linux 桌面 | amd64 + arm64 | `patnest-2.0.2-linux-<arch>.deb` / `.rpm` / `.AppImage` / `.tar.gz` |
| Windows 桌面 | x64 + arm64 | `patnest-2.0.2-windows-<arch>.msi` |
| macOS 桌面 | 仅 arm64 | `patnest-2.0.2-macos-arm64.dmg` |
| Android | 仅 arm64-v8a | `patnest-2.0.2-android-arm64.apk` |
| 小程序 | 源码包 | `patnest-uniapp-2.0.2.zip` |

## 已知限制

沿用 v2.0.1：

- 支付仍为模拟网关，不接真实资金渠道；
- 演示环境应用服务器与数据库跨地域，列表接口首屏约 1.5~3 秒；
- 桌面端没有图形化的「修改服务地址」入口；
- macOS dmg 仅 Apple Silicon；Android 仅 arm64-v8a；
- 未做大规模并发压测。

## 校验

部署包内的 `update-manifest.json` 记录 API、迁移工具与管理后台静态文件的 size / sha256；安装包可在下载后用 `sha256sum` 自行校验。发布说明正文来自 `docs/release/v2.0.2.md`。
