# PatNest 宠栖 v1.2.0

本次发布集中在**安全能力**、**证书运维**与**客户端稳定性**三块：管理后台补齐两步验证，HTTPS 证书改为自动签发续期，三端修掉一批会导致下单失败、金额不准、消息看不到的缺陷。

## 版本亮点

- 管理后台支持 TOTP 两步验证，管理员账号被盗也不能只靠密码登录。
- Let's Encrypt 证书接入后台，Cloudflare DNS-01 签发，不占用 80 端口，到期自动续期。
- 小程序与 KMP 客户端修复 33 处逻辑与 UI 缺陷，其中 11 处会直接导致功能不可用或资金出错。
- 建立 GitHub Actions 发布流水线，打 tag 即出四类产物并自动生成 Release。

## 升级说明

- **数据库**：需执行迁移 `serverdb/migrations/0023_admin_totp.sql`（新增 `users.totp_*` 字段与 `totp_recovery_codes` 表），可在线执行，无需停机；新库直接跑 `serverdb/init.sql` 即可。
- **配置**：证书自动签发需要在后台填写 Cloudflare API Token（Zone:DNS:Edit 权限），Token 只落库不回显；未配置时手动证书流程不受影响。
- **端口**：签发走 DNS-01，服务器不需要开放 80 端口。
- **客户端**：小程序需用 HBuilderX 重新编译上传；Android 与桌面端需重新安装；旧版本客户端仍可访问新后端，但会缺少上述修复。
- **管理后台**：已启用两步验证的账号登录时会要求输入动态码，请提前保存恢复码。

## 已知问题

- 应用服务器与数据库跨地域部署，列表接口首屏约 1.5~3 秒，尚未做服务端缓存。
- 未知路由返回 404 且响应体为空，部分客户端只能显示通用错误。
- 商家未开通机构时，相关接口在 200 与 404 之间不一致。
