# PatNest 宠栖 v2.0.5

> 发布时间：2026-11-14 · 类型：客户端维护版（下拉刷新收回修复）
> 服务端无任何变更，已部署的环境**不需要重新部署**。

这是 v2.0.4 后的快速跟进版：修复下拉刷新指示条在部分场景下刷新结束后不消失、一直显示的问题，并按反馈把转圈图标改为纯文字提示。

## 修复

### 下拉刷新指示条刷新结束后不消失（主要修复）

v2.0.3 / v2.0.4 的下拉刷新，在部分场景下会出现「刷新已经完成，顶部指示条却一直留着不收回」的问题：

- 快速完成的刷新：加载状态 true→false 在界面重组观察到之前就已结束，旧的收回逻辑观察不到「刷新结束」这一变化，指示器永远收不回。
- 重复触发：上一次加载还在进行中再次下拉时，刷新请求被直接忽略，指示条卡在拉出的位置不动。

修复后：

- 收回逻辑改为持续观察刷新状态，无论刷新多快结束都会收回；
- 松手触发刷新时立即把指示条钉在固定高度，不再依赖外部状态变化；
- 刷新请求被忽略时（150ms 内未开始加载）自动收回指示条。

### 去掉转圈图标

按反馈移除了转圈图标——它只要可见就会一直自转，收回稍有延迟就会造成「还在转」的观感。指示条现在只显示三态文字：**下拉刷新 → 松手刷新 → 正在刷新…**，随收随走。

## 已知限制（与 v2.0.4 相同）

- Android 仅支持 arm64-v8a 设备；macOS 仅提供 Apple Silicon 版本。
- 演示环境支付为模拟网关；跨洋数据库延迟偶发明显。
