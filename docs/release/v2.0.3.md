# PatNest 宠栖 v2.0.3

v2.0.2 之后的维护版本，**服务端接口与数据库无变更**（仅一处评价状态口径修正，随包附带）。本版聚焦 KMP 客户端（Android）的日常使用体验：全部列表页支持下拉刷新，并修复一批页面与逻辑问题。

## 版本亮点

- Android 端 13 个列表页全部支持**下拉刷新**：机构列表、我的订单、我的宠物、寄养动态、我的收藏、优惠券、消息通知、机构工作台、接单管理、我的积分、收益结算、机构优惠券、我的评价。
- 所有刷新走各页面的 `force` 重载，下拉一下即可看到最新订单状态、钱包余额与公告，不再需要退出页面重进。
- 后台代录的评价现在会把订单推进到「已评价」，与主人端自己评价的口径一致。

## 下拉刷新实现说明

- 自研 `DPullRefresh` 容器组件（`NestedScrollConnection` 捕获「列表已在顶部时继续下拉」的剩余手势），不依赖 accompanist，也不要求 material3 版本自带 PullToRefresh。
- 拉动超过 64dp 松手即触发刷新，刷新期间指示器钉在 44dp；低于阈值松手自动回弹。
- 集成进 `DFrame` / `DLazyFrame` 两个页面骨架，列表页只需要传 `refreshing` / `onRefresh` 两个参数。

## 逻辑修复

| 模块 | 问题 | 处理 |
| --- | --- | --- |
| Android · 订单 | 「已评价」页签看不到订单 | 后台代录评价未同步订单状态（与主人端口径分叉），已修复并同步历史数据 |
| Android · 各列表 | 列表数据陈旧：后台造数 / 另一端操作后，页面不重进就看不到变化 | 全列表页接入下拉刷新 + 强制重载 |
| Android · 收益页 | 下拉刷新与强制重载入口缺失 | 与工作台一致的整组刷新（收益 / 结算 / 统计 / 可结算区间） |

## 升级说明

- **服务端**：`admin_reviews.go` 有小改动（评价后同步订单状态），重新构建并替换 `patnest-api` 即可；无数据库迁移、无接口变更。
- **Android**：直接安装新 APK；v2.0.2 用户可直接覆盖。
- **桌面端 / 小程序**：本版逻辑改动集中在 Android 列表交互，桌面端与小程序无功能变化，仅版本号对齐。

## 产物与架构

命名规范与 v2.0.2 相同（`patnest-<版本>-<平台>-<架构>.<格式>`），共 15 个附件。

| 端 | 支持架构 |
| --- | --- |
| 服务端 / 容器 | amd64 + arm64 |
| Linux 桌面 | amd64 + arm64 |
| Windows 桌面 | x64 + arm64 |
| macOS 桌面 | 仅 arm64 |
| Android | 仅 arm64-v8a |

## 已知问题

沿用 v2.0.2：

- 支付仍为模拟网关，不接真实资金渠道；
- 桌面端（Windows / macOS / Linux）暂无下拉刷新需求，未加入；
- 未做大规模并发压测。

## 校验

部署包内的 `update-manifest.json` 记录 API、迁移工具与管理后台静态文件的 size / sha256；安装包可在下载后用 `sha256sum` 自行校验。发布说明正文来自 `docs/release/v2.0.3.md`。
