# PatNest 宠栖 v2.0.4

> 发布时间：2026-11-14 · 类型：客户端维护版（平板适配）
> 服务端无任何变更，已部署 v2.0.2/v2.0.3 服务端的环境**不需要重新部署**。

这是一个小而重要的维护版本：修复 v2.0.3 引入的下拉刷新在平板等宽屏设备上的显示问题，并顺带修掉一处宽屏拉伸。手机用户无感知变化，可以不升级；平板用户建议升级。

## 修复

### 平板下拉刷新显示错乱（主要修复）

v2.0.3 为 13 个列表页接入的下拉刷新，在平板（Medium / Expanded 宽度档）上会出现「页面正文整块贴在左边，与居中的顶栏、底栏、刷新指示器脱节」的观感。

- 根因：下拉刷新容器内部负责「内容随手势下移」的盒子没有设置对齐方式，默认左上。手机上正文是全宽的看不出差异；平板上正文被限宽（800~1040dp）并应居中，于是暴露。
- 修复：容器新增 `contentAlignment` 对齐参数并与页面骨架保持一致，13 个页面（找机构、我的订单、寄养动态、我的宠物、我的收藏、优惠券、消息通知、机构工作台、接单管理、我的积分、收益结算、机构优惠券、我的评价）自动修正。
- 手机的下拉刷新交互与 v2.0.3 完全一致：超过阈值松手刷新，不足回弹。

### 容量日历宽屏拉伸

机构端「容量管理」的月历格子按 7 列均分，平板上每格会被拉成约 130dp 宽的色块。现在每列占位（触控区）不变，格子本身限宽 44dp 并在列内居中，手机版式不变。

## 其他

- 全量排查了 60 个屏幕在手机 / 平板两种宽度档下的表现：页签行、筛选 chips（可横滚）、聊天气泡、机构对比、首页 hero、结算栏、空态等均确认正常。
- 本版未改动任何业务逻辑与后端接口；桌面端（Windows / macOS / Linux）无功能变化，仅版本号对齐。

## 已知限制（与 v2.0.3 相同）

- Android 仅支持 arm64-v8a 设备（2019 年后的主流机型均覆盖），32 位 ARM / x86 设备不支持。
- macOS 仅提供 Apple Silicon 版本。
- 演示环境支付为模拟网关；跨洋数据库延迟偶发明显。
