# PatNest 宠栖 v2.0.0

宠栖的第一个正式版本。从最初的数据库设计与接口约定，到主人端、机构端、管理后台三套界面与完整的资金/容量账目，这一版把整条业务链路跑通并做了一轮系统级联调，作为可交付、可自行部署的基线版本发布。

## 关于宠栖

宠栖是一个宠物寄养服务预约平台，把「找机构 → 预约寄养 → 支付 → 寄养过程记录 → 完成结算 → 评价反馈」串成一条闭环。系统围绕三类角色组织：

- **主人**：浏览机构、按宠物与日期下单、支付、查看寄养动态、评价与售后。
- **机构**：开店与资质审核、设置接待容量与价格、接单、发布动态、处理退款与结算。
- **管理员**：机构与用户审核、订单与资金、内容与优惠券、系统更新与证书、审计日志。

## 这个版本包含什么

### 主人端（微信小程序 / Android / 桌面端）

| 能力 | 说明 |
| --- | --- |
| 机构发现 | 首页推荐与筛选、按距离排序、地图选点、收藏与对比 |
| 下单 | 宠物与日期选择、实时估价、优惠券、积分抵扣、加购服务 |
| 支付 | 钱包余额支付，支持充值、提现申请与资金流水 |
| 订单 | 待支付 / 已确认 / 寄养中 / 已完成全状态跟踪，支持取消、改期、续费 |
| 寄养过程 | 机构动态查看、评价、追评、工单与售后 |
| 账户 | 手机号注册登录、资料与地址簿、邀请码、消息通知 |

### 机构端

资质申请与店铺装修、接待容量日历（按日设置上限与临时关闭）、按日/按次定价、加购服务管理、接单与拒单、动态发布、优惠券、收入与结算、评价回复。

### 管理后台

18 个业务页面：经营看板、机构与订单、宠物与动态、评价、优惠券、公告与推送、售后、机构结算、钱包、用户与权限、审计日志、系统更新（含热更新与 HTTPS 证书）、账号安全。

### 服务端

Go + Gin + PostgreSQL + Redis + MinIO，170 条路由、212 个接口操作覆盖三端全部调用；蓝绿双槽位发布、在线数据库迁移、接口文档自动生成（Swagger）、分级鉴权限流与审计、地理编码、容量台账一致性校验。

### 安全与运维

- 管理员两步验证（TOTP），支持恢复码与管理员重置；
- Let's Encrypt 证书在后台申请与续期，Cloudflare DNS-01 签发，无需开放 80 端口；
- 后台可上传证书、查看服务状态、执行热更新与回滚。

## 部署与安装

### 服务端

需要一台 Linux 服务器（Podman 或 Docker + Compose v2）、PostgreSQL 14+、Redis、兼容 S3 的对象存储（MinIO 即可）。

```bash
unzip patnest-docker-2.0.0.zip && cd patnest-docker-2.0.0
cp env.example .env            # 填数据库、Redis、对象存储、JWT_SECRET
psql -U postgres -d patnest_db -f db/init.sql    # 全新库一次建好结构与种子数据
podman-compose --profile app up -d --build
```

启动后访问 `http://<host>:9200/` 进入管理后台，`/swagger/index.html` 为接口文档。HTTPS 可在后台「系统更新」页申请证书，无需停机。

### 客户端

APK 与桌面安装包直接安装即可；桌面端首次运行会在安装目录查找 `.env` 读取服务地址，也可以在启动前设置 `PATNEST_API_BASE` 环境变量。小程序需在 HBuilderX 中导入工程，按自己的小程序 AppID 与合法域名配置后发行。

## 已知限制

诚实说明，便于评估适用范围：

- **支付为模拟网关**：本版用于教学与演示，不接真实资金渠道，充值与支付不产生实际扣款。
- **部署环境跨地域**：当前演示环境应用服务器与数据库不在同一地域，列表接口首屏约 1.5~3 秒，尚未做服务端缓存。
- **地图与定位依赖高德 Key**：未配置 Key 时地图降级为地址解析与瓦片底图。
- **小程序需自行发行**：CI 只产出工程源码包，编译上传仍走 HBuilderX + 微信开发者工具。
- **未做高并发压测**：容量与资金账目在功能层面有一致性校验，但没有针对大规模并发的性能基线。
