# PatNest 宠栖 v2.3.0

> 发布时间：2026-11-22 · 类型：功能测试版（正式 Release，非预发布）
>
> **本版用于验证发布流程与端到端联调，不建议用于生产环境。**
> 要验证的是：tag 驱动的流水线能否把服务端部署包、桌面安装包、APK 与小程序工程包完整产出，以及三端与后端的接口契约是否一致。

v2.0.5 之后累积的三批改动合成这一版：Android 端 UI 换成液态玻璃视觉、手机号验证码登录（演示模式）、机构搜索与相似推荐升级。版本号从 2.0.5 直接到 2.3.0，是为了把这三批改动的体量与普通维护版区分开。

## 版本亮点

- **液态玻璃 UI**：Android 端全部页面改为玻璃质感，边缘折射、色散、顶部光带与文字阴影一并落地。
- **验证码登录**：手机号 + 6 位验证码登录；演示模式下验证码由接口返回、由 App 本地通知展示。
- **搜索与推荐**：机构搜索优先走中文全文检索，机构详情页新增「相似机构」推荐与距离展示。
- **发布流程验证**：本版同时用于确认多架构流水线、产物命名与 Release 正文来源是否仍然成立。

## 新增功能

| 模块 | 内容 |
| --- | --- |
| 服务端 | 验证码登录：`POST /auth/send-code` 与 `POST /auth/login/code`，60 秒重发间隔、10 分钟最多 5 次，验证码 5 分钟有效、一次性使用、错误 5 次作废 |

| 服务端 | `GET/PUT /admin/settings/swagger`：Swagger 运行期开关，关闭后文档返回 404，业务接口不受影响 |
| Android | 全量液态玻璃视觉：页面级背景记录 + 窗口级环境光两层结构，卡片、输入框、顶栏、底栏、底部 Tab、地图浮层统一玻璃化 |
| Android | 登录页支持手机号 + 验证码，演示模式验证码用本地通知展示 |
| Android | 机构详情页新增「相似机构」区块；机构列表与首页「附近推荐」显示距离 |
| 小程序 | 距离排序改为服务端完成，没有参考点时退回本地排序；机构详情页新增相似机构区块 |
| 管理后台 | 「账号安全」页新增接口文档（Swagger）开关 |

## 问题修复

| 模块 | 问题 | 处理 |
| --- | --- | --- |
| Android | 首帧渲染时玻璃层在记录层内采样自身图层，触发 SIGSEGV | 背景记录与玻璃拆成两层，玻璃只采外层背景，不再形成 GPU 反馈环路 |
| Android | 玻璃外圈出现深灰 / 黑色描边、边缘锯齿 | 折射带外溢后按全分辨率裁切收边，轮廓在着色器内平滑淡出 |
| Android | 暗色模式下玻璃上的文字发糊、对比度不足 | 按表面分级提高玻璃 tint，调整次级文字与品牌色，合成后对比度约 4.8:1 |
| Android | 选点页顶部与玻璃面板内布局错位 | 修正嵌套作用域与大括号，面板内恢复纵向排列 |
| 服务端 | 机构列表 `sort=distance` 时总数统计多收到经纬度参数 | 计数查询挪到追加距离参数之前 |
| 服务端 | PGroonga 对 VARCHAR 列建普通索引，查询经 `::text` 转换后索引用不上 | 改为表达式索引，与查询的 cast 完全一致 |
| 管理后台 | 关闭 Swagger 后需要重启后端才生效 | 开关写入平台参数表并即时更新运行期状态，重启后以数据库值为准 |

## 升级说明

**数据库（本版必做）**

- 新增迁移 `0024`~`0027`：PGroonga 全文索引、机构特征向量、PGroonga 表达式索引、验证码表。
- `0024` / `0026` 在缺少 PGroonga 扩展时只记录 NOTICE、不阻断迁移，搜索自动退回 pg_trgm。
- **`0025` 依赖 pgvector 扩展**：目标库没有该扩展时迁移会直接失败，请先在镜像或实例上安装。
- 新库直接执行 `init.sql` 即可，已包含以上全部结构与索引；老库按顺序执行 `cmd/migrate`。
- 迁移不需要停机，建议低峰执行并先做备份。

**配置**

- 新增 `AUTH_CODE_DEMO`（默认 `true`）。演示模式会把验证码返回给客户端，**正式环境必须设为 `false`**，并接入真实短信 / 邮件通道。
- `SWAGGER_ENABLED` 改为默认值语义：后台保存过开关后以数据库为准，环境变量只在没有记录时生效。

**客户端**

- Android / 桌面 / 小程序均需重新安装或导入，旧版本仍可正常访问后端。
- 液态玻璃效果仅 Android 13（API 33）及以上生效，低版本自动回退为不透明卡片。

## 已知问题

- 验证码登录只用于演示，没有真实短信通道，不能作为手机号归属验证。
- 液态玻璃在部分低端机上可能掉帧，性能优化留待后续版本。
- 小程序工程新增的鸿蒙（app-harmony）配置尚未在鸿蒙设备上验证。
- 本版同时用于校验流水线：若某个架构构建失败，Release 附件里会缺少对应产物，以实际附件为准。
